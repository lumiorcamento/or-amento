# Configuração do Link LumiIA na Nuvemshop

Para este MVP, não é necessária uma integração técnica via API (OAuth) com a Nuvemshop. Você só precisa adicionar o link do seu assistente de IA na sua loja.

## Passo a Passo

1.  Acesse o painel da sua **Nuvemshop**.
2.  Vá no menu lateral em **Loja online** > **Menus**.
3.  Escolha o menu onde deseja adicionar o assistente (geralmente o **Menu Principal**).
4.  Clique em **Adicionar novo item ao menu**.
5.  No campo **Nome**, digite algo chamativo, como:
    *   `Criar orçamento personalizado com IA`
    *   `Orçamento Inteligente`
    *   `Comprar com ajuda da IA`
6.  No campo **Link**, cole a URL do seu assistente que você encontra no painel do lojista em **Conectar**:
    *   Exemplo: `https://lumiia-black.vercel.app/s/lumi-kids/orcamento?source=nuvemshop`
7.  Clique em **Adicionar** e depois em **Salvar alterações**.

---

## Onde mais posso colocar o link?

Além do menu principal, você pode aumentar a conversão colocando o link em:

-   **Banners da Home**: Crie um banner chamando para o "Personal Shopper IA".
-   **Rodapé**: Adicione um link na seção de Ajuda ou Atendimento.
-   **Páginas de Categoria**: Se você vende produtos técnicos ou que exigem consultoria, coloque o link no topo dessas páginas.
-   **Instagram/Bio**: Use o mesmo link na sua Bio do Instagram para captar orçamentos direto por lá.

---

## Como funciona o fluxo?

1.  O cliente clica no link na sua loja.
2.  Ele é levado para o LumiIA.
3.  A IA usa o catálogo que você sincronizou do **Bling** para sugerir os produtos.
4.  O orçamento é gerado e você recebe a notificação no painel do LumiIA.
